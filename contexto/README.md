# Contexto de PreciosPY

Esta carpeta existe para retomar el proyecto rapido en nuevas sesiones.

Orden recomendado de lectura:

1. `estado-actual.md`
2. `arquitectura.md`
3. `comandos.md`
4. `decisiones.md`
5. `proximos-pasos.md`

Reglas importantes:

- No subir ni tocar `.env`, `.env.save` ni secretos.
- `blockbench/` y `labs/` estan sin seguimiento y no pertenecen al flujo principal, salvo que el usuario lo pida explicitamente.
- Antes de editar, correr `git status --short`.
- Antes de subir, correr tests relevantes y luego `git push`.
- El dashboard local suele estar en `http://127.0.0.1:8501`.
